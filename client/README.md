# Rolefit client

The React + Vite frontend for Rolefit, an AI-assisted applicant tracking system.

## Run locally

```bash
cd client
cp .env.example .env
npm install
npm run dev
```

The client expects the API at `http://localhost:5000/api` by default. Set `VITE_API_BASE_URL` in `.env` to point to another server.

For the seeded recruiter account, use `recruiter@demo.com` and `Password123`.
